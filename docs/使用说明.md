# 使用说明

## 离线体验

1. 打开 App，无需登录。
2. 在主页点击“打开示例文档”，阅读项目自带的原创 Markdown 文档。示例只导入一次，重复打开保留阅读进度。
3. 在书架右上角导入自己有权使用的 EPUB、PDF、TXT、Markdown 或 DOCX 文件。不同格式的编辑和批注能力有所不同。
4. 在阅读器中选中文字，使用相应格式支持的高亮、批注或笔记功能；在“笔记”集中查看。
5. 在“画布”新建原生画布，绘制、输入文本或插入图片。画布保存到本地，可通过列表菜单导出 JSON，之后再导入。

## 可选网络功能

- AI：在“我的 → 更多设置 → AI 配置设置”中自行配置供应商地址、模型和密钥。纯阅读不依赖 AI 服务。发送书籍内容、图片或附件前，请自行确认数据处理范围。
- Agent：使用前确认模型与工具配置，查看任务计划和工具授权，再执行。可在任务列表查看历史或取消。
- MCP：在 AI 配置中添加服务器；HTTP 服务需要可访问的地址，桌面 stdio 服务需要本机可执行程序。只连接可信的服务。
- WebDAV：在“更多设置 → 备份与同步”配置自己的服务器和凭据。建议先用测试目录验证备份及恢复，再接入日常数据。
- 单词卡片：`serverless/` 是可选的 Python 服务，需要自行部署和配置环境变量。仓库不提供共享服务地址或密钥。

## 数据与构建

书架、阅读进度、笔记、画布和历史记录保存在应用本地目录。云同步只在使用者自行配置后启用。AI/翻译等网络功能会向所选服务发送相关内容，具体范围由操作和配置决定。

Android 展示版包名为 `io.github.zzy19074244935.libranote`，与原有私有版本分开安装，不自动迁移原版本的数据。

当前主要开发目标是 Android 和 Windows；仓库中保留其他平台脚手架不代表已验证这些平台。该项目是个人实践作品，跨设备同步、真实模型服务及不同格式文档仍需根据实际环境验证。
