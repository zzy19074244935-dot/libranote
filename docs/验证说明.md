## 重点验证

- 无书库账号启动，直接进入本地主页。
- 示例文档可写入本地书架，重复打开保留进度且不重复导入。
- 新装数据库可保存学习时长；版本 17 缺少学习统计表的数据库可通过升级修复。
- 320、390、768 宽度下浮动导航可点击，保留安全区和内容空间。
- 六个模块切换、深浅主题、键盘弹出及大字号导航。
- Agent 取消、页面退出与任务恢复；文档解析、编辑与部分阅读组件。

## 环境与限制

验证机器使用 Windows、Flutter 3.44.9 / Dart 3.12.2。PDFium 首次下载受网络影响，本轮复用了开发机已经缓存的相同版本原生库；新环境需要能够访问对应的 GitHub Releases 下载。

分析器不检查 `third_party/` 的上游风格规则；运行时依赖仍参与应用编译和测试。界面测试使用空的内存数据夹具，数据库行为另外通过真实 SQLite 测试；截图不是已完成真机验收的证据。

Android 构建存在 Gradle 8.13 的未来支持警告，本次构建成功，尚未升级构建工具链。调试 APK 使用开发签名，未作为正式 Release 发布。
