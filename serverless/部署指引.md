# 单词卡片 Serverless 后端部署指引

拍照生成单词卡片的后端：火山引擎函数计算（veFaaS，Python 3.10）+ 对象存储 TOS。
本目录包含可直接部署的 `main.py`、`requirements.txt`、字体 `fonts/` 与打包脚本。

## 架构数据流

```
App 拍照/选图（长边≤1280、70%质量）
  → HTTP POST multipart → 函数公网 URL /create_card
    （请求头 Authorization: Bearer <APP_TOKEN>）
  → ① 校验 Token（403 拒绝）
  → ② 火山视觉智能 cv 通用分割（抠图，透明 PNG）
  → ③ 豆包视觉理解（方舟 Ark）识别物体 → 中文标签
  → ④ 火山机器翻译（中文 → 英文单词）
  → ⑤ DeepSeek（英美音标 + 简短释义，JSON 输出）
  → ⑥ 豆包语音大模型 TTS（英音 + 美音 mp3）
  → ⑦ Pillow 内存合成卡片图（全程 BytesIO，不落盘）
  → ⑧ 抠图 PNG / 卡片图 / 两段 mp3 上传 TOS，生成公网 URL
  → 返回 JSON → App 下载资源存本地（离线可看可听）
```

函数临时磁盘请求结束即销毁，**所有文件必须上传 TOS**，代码里全部用内存流。

> ⚠️ 与原方案文档的三处重要差异（调研核实）：
> 1. 火山经典「智能视觉」**没有通用图像标签接口**，识别改用**方舟 Ark 豆包视觉理解**（Bearer API Key）。
> 2. TTS 不用 AK/SK，用**豆包语音大模型 V3** 的 `X-Api-Key`（新版控制台单独创建）。
> 3. DeepSeek 模型名现在是 `deepseek-v4-flash`（`deepseek-chat` 已停用）。

## 一、部署前准备（控制台手动操作）

1. 火山引擎注册 + 实名认证，拿到 **AK/SK**（访问控制 → 密钥管理）。
2. 开通服务：
   - 函数计算 veFaaS
   - 对象存储 TOS
   - 视觉智能（cv，含「通用分割」抠图）
   - 机器翻译（translate）
   - **方舟 Ark**（豆包视觉理解，识别物体）
   - **豆包语音大模型**（TTS）
3. 创建 TOS 桶：地域**广州**、**公共读**，建 `card_img/`、`audio/` 两个文件夹。记录桶名。
4. 创建密钥（两把，与 AK/SK 不同）：
   - **ARK_API_KEY**：方舟控制台 → API Key 管理（console.volcengine.com/ark/region:ark+cn-beijing/apiKey）
   - **VOLC_TTS_API_KEY**：豆包语音新版控制台 → API Key 管理（console.volcengine.com/speech → API Keys）
5. DeepSeek 开放平台（platform.deepseek.com）创建 **API Key**。
6. 自定一个 **APP_TOKEN**（随便一串长随机字符串，和 App 设置里一致）。

## 二、创建函数

- 函数类型：**HTTP 触发器（Web 函数）**
- 运行环境：**Python 3.10**，地域：**广州**（与 TOS 同地域）
- 内存 512MB，超时 **60 秒**（流水线串行调 5 个云 API，30s 偏紧）

环境变量（函数控制台 → 环境变量）：

| 键 | 值 | 说明 |
|---|---|---|
| `VOLC_ACCESSKEY` | 你的 AK | 抠图/翻译/TOS 用 |
| `VOLC_SECRETKEY` | 你的 SK | 同上 |
| `ARK_API_KEY` | 方舟 Key | 图像识别（豆包视觉） |
| `ARK_VISION_MODEL` | 按控制台实际开通名 | 默认 `doubao-seed-1-6-250615`，若方舟里模型名不同必须改 |
| `VOLC_TTS_API_KEY` | 豆包语音 Key | TTS |
| `VOLC_TTS_RESOURCE_ID` | `seed-tts-2.0` | 可选 |
| `TTS_SPEAKER_US` | `en_male_tim_uranus_bigtts` | 美音音色（已核实） |
| `TTS_SPEAKER_UK` | （先留空） | 英音音色 ID 需在豆包语音控制台「音色列表」按你账号确认后填；留空则英音回退美音音色 |
| `DEEPSEEK_API_KEY` | DeepSeek Key | 音标释义 |
| `APP_TOKEN` | 自定 Token | 与 App 设置一致 |
| `TOS_BUCKET` | 桶名 | |
| `TOS_ENDPOINT` | `tos-cn-guangzhou.ivolces.com` | 内网（省流量），公网 URL 自动转外网 |
| `TOS_REGION` | `cn-guangzhou` | |
| `TOS_PUBLIC_BASE` | 可选 | 自定义域名时才填 |

## 三、打包上传代码

Windows（PowerShell）：

```powershell
cd serverless
.\build_function.ps1      # 产出 function.zip
```

WSL / Linux：

```bash
cd serverless
bash build_function.sh    # 产出 function.zip
```

脚本做的事：`pip install -t deps -r requirements.txt` → 组装 main.py + fonts/ → 打 zip。
在 veFaaS 控制台**上传 zip 代码包**，入口 `main.py`，监听端口 9000。

> 依赖较多（volcengine 会带不少传递依赖），zip 约 20~40MB，上传稍慢属正常。
> 中文字体 NotoSansSC.ttf（17MB）已打进 zip，保证卡片中文不显示豆腐块。

## 五、常见错误排查（函数控制台 → 函数日志，每步失败都有 `[card]` 前缀日志）

| 现象 | 原因 | 处理 |
|---|---|---|
| 403 | Token 不一致 | 核对 App 设置与函数环境变量 `APP_TOKEN` |
| `general_segment code=...` | 抠图 API 报错 | 视觉智能 cv 未开通/欠费/图片过大；日志里有 code 与 msg |
| `Ark HTTP 401` | ARK_API_KEY 错 | 方舟控制台重新复制 Key；确认模型名与开通一致 |
| `Image recognition failed` | 识别无结果 | 换更清晰、主体更大的照片；看日志里模型返回 |
| `翻译API错误` | AK/SK 或翻译服务问题 | 机器翻译未开通/欠费 |
| `DeepSeek HTTP 401` | Key 错或模型名错 | 用 `deepseek-v4-flash`；DeepSeek 无免费额度，需先充值小额 |
| `TTS HTTP ...` | 豆包语音配置错 | 核对 X-Api-Key、Resource-Id；TTS 失败不阻断卡片生成 |
| 上传 TOS 失败 | 桶名/Endpoint/权限 | 核对环境变量；桶必须公共读 |
| 整体 504 超时 | 流水线超过函数超时 | 把函数超时调到 60 秒 |

## 六、成本（内测规模 ≈ 0 元，DeepSeek 除外）

- 函数计算 / TOS / 视觉智能 / 翻译：免费额度足够几十人内测。
- 豆包视觉（Ark）与豆包语音：按量计费，单词场景调用量极小。
- DeepSeek：**无免费额度**，需先充值小额（单词很短，token 极少，几元用很久）。
